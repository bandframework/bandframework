This directory contains examples of the application of the BAND tools, found [here](https://github.com/bandframework/software), to nuclear-physics problems. As of v0.5 we have the following examples:

- [Bfrescox](/software/Bfrescox): A BAND extension of the frescox scattering code for coupled-channels calculations that uses surmise to enable parameter estimation within frescox.
- BMEX ([v0.1.1](https://github.com/massexplorer/bmex-masses/releases/tag/v0.1.1 )): A web application for exploring quantified theoretical model predictions of nuclear masses and related quantities.
